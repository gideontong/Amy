# Introduction

Thanks for considering making a contribution to Amy! People like you make Amy
who she is today. Following the guidlines outlined in this document helps to
communicate that you respect the time of the developers in managing and pushing
forward the goalposts of this open source project. In return, we'll try to
reciprocate that respect by addressing your issue, assessing changes, and
helping you finalize your pull requests.

If you have any questions, please join the
[708 Innovations Discord server](https://discord.gg/WUGMTcZ).

## What We Need

If you find an issue or a bug, or have a feature request, please navigate to the
[bug tracker on GitHub](https://github.com/gideontong/Amy/issues) or submit a
pull request. The team will read through your pull request or issue and decide
upon its importance and priority, as well as whether or not to merge any changes
you have requested or proposed.

The current biggest need is improving the current documentation on how to get
started in both development and usage of Amy. The documentation has been
out-of-date since June 2020 and as the bot has completely been rewritten from
TypeScript to Python, nearly all of the docs are now outdated. On top of that,
it would be helpful to document how to set up the bot.

As an open source project, we'd love to receive contributions from our community
\- which includes you, since you're reading this! There are many ways to
contribute, and you can help out by spreading the word about Amy through online
social media posts or even trying her out for yourself and proposing new
features.

## What We don't Need

If you have any support questions, please do not file an issue on the issue
tracker. Instead, please post in the `#american-news` channel in the
[708 Innovations Discord server](https://discord.gg/WUGMTcZ).
